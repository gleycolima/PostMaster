# PostMaster – Plataforma de Postagens Interativa

## 📘 Descrição do Projeto
O **PostMaster** é uma página web interativa que permite criar e visualizar posts dinamicamente, simulando uma plataforma de blog ou rede social.  

Funcionalidades principais:
- Criar posts com **título** e **conteúdo** através de um formulário.  
- Renderizar o post imediatamente na tela, dentro de uma seção de **preview**.  
- Estrutura moderna e responsiva, pronta para desktop e dispositivos móveis.  
- Projeto desenvolvido como parte do **Projeto de Certificação 2 – Trilha 2 DEVstart**.

---

## 🧰 Tecnologias Utilizadas
- **HTML5** – Estrutura semântica da página (`header`, `main`, `section`, `article`, `aside`, `footer`).  
- **CSS3** – Layout moderno, responsivo, com cards e botões estilizados.  
- **JavaScript** – Manipulação do DOM e interação com inputs para renderização dinâmica.
